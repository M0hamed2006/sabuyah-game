## 🎯 إيه هو "المصري الذكي"؟

المصري الذكي هو **تطبيق ويب** بيستخدم **ذكاء اصطناعي حقيقي** (TensorFlow.js + MobileNet) عشان:

- 📸 **يتعرف على الصور** من الكاميرا أو الملفات
- 💬 **يرد على أسئلتك** باللهجة المصرية
- 😂 **يقولك نكت مصرية** تضحكك
- 🌐 **يشتغل من غير نت** بعد أول تحميل
- 🇪🇬 **يفتخر بمصر** في كل رد

---

## 🚀 المميزات

| الميزة | الوصف | التقنية |
|--------|-------|---------|
| 🤖 **تعرف بصري** | يشوف صورة ويقول "ده كشري!" أو "ده أهرامات!" | MobileNet CNN |
| 💬 **شات بوت ذكي** | يسأله عن مصر، الأكل، التاريخ، الرياضة | Rule-based AI + Knowledge Base |
| 📱 **يشتغل على الموبايل** | تصميم responsive، كاميرا حقيقية | MediaDevices API |
| 🌐 **Offline Mode** | يشتغل من غير نت بعد أول مرة | Service Worker + IndexedDB |
| ⚡ **سريع** | ما يحتاجش server، كل حاجة في المتصفح | Client-side inference |
| 🎨 **تصميم عصري** | Dark mode، animations، glassmorphism | CSS3 + Canvas |
