## 🎮 نبذة عن اللعبة

لعبة صابويه هي نسخة محسّنة وأفضل من Subway Surfers! استوحيت من لعبة الركض الشهيرة، لكن طورتها بطريقة احترافية مع ميزات متقدمة وأصوات مدمجة وتصميم عصري.

**اللعبة تركز على:**
- الركض اللانهائي عبر 3 مسارات
- تجنب العقبات (القطارات والسيارات والحواجز)
- جمع العملات والعناصر المعززة
- نظام نقاط متطور مع مضاعفات
- صعوبة متزايدة مع التقدم
- أصوات وموسيقى مدمجة
- حفظ أعلى نتيجة

---

## ✨ المميزات الرئيسية

### 🎯 ميكانيكيات اللعبة
- **3 مسارات للحركة**: تنقل بين المسارات بسهولة
- **القفز والانزلاق**: اجمع بين الحركات لتجنب العقبات
- **نظام فيزياء واقعي**: جاذبية طبيعية وحركة سلسة
- **صعوبة متزايدة**: كل 500 نقطة تزيد السرعة

### 🎁 العناصر المعززة (Power-Ups)
- **🧲 المغناطيس**: اجذب العملات من حولك
- **✈️ الجيتباك**: اطر في الهواء لتجاوز العقبات
- **🛡️ الحماية**: حماية مؤقتة من الاصطدامات
- **×2 المضاعف**: ضاعف نقاطك لفترة محدودة

### 📊 نظام النقاط
- **العملات**: +10 نقاط لكل عملة
- **المسيرات المتتالية**: +1 نقطة كل 10 إطارات
- **الإنجازات**: شارات خاصة عند تحقيق أهداف معينة
- **حفظ أعلى نتيجة**: يتم حفظها محلياً على الجهاز

### 🔊 الأصوات والموسيقى
- **أصوات القفز والعملات**: مدمجة برمجياً
- **موسيقى الخلفية**: حلقة موسيقية مستمرة
- **تحكم الصوت**: ضبط مستوى الصوت وكتمه
- **تأثيرات صوتية**: لكل حدث في اللعبة

### ⚙️ الإعدادات المتقدمة
- **مستويات الصعوبة**: سهل، عادي، صعب
- **مستوى الصوت**: قابل للتعديل من 0-100%
- **الاهتزاز**: تفعيل/تعطيل الاهتزاز على الهواتف
- **حفظ الإعدادات**: يتم حفظ جميع الإعدادات محلياً

### 📱 استجابة الشاشات
- **سطح المكتب**: تجربة كاملة مع الماوس والأسهم
- **الأجهزة اللوحية والهواتف**: تحكم باللمس حساس
- **جميع الأحجام**: تصميم مستجيب يتكيف مع جميع الشاشات

## 💻 البنية التقنية

```
sabuyah-advanced/
├── index.html          # الهيكل الرئيسي
├── style.css           # التنسيقات والرسوم المتحركة
├── game.js             # منطق اللعبة الرئيسي
├── soundGenerator.js   # إنشاء الأصوات برمجياً
└── README.md           # هذا الملف
```

### التقنيات المستخدمة
- **HTML5**: الهيكل القياسي
- **CSS3**: تنسيقات حديثة ورسوم متحركة
- **JavaScript (ES6+)**: منطق اللعبة المتطور
- **Canvas API**: رسم العناصر والرسوم المتحركة
- **Web Audio API**: إنشاء الأصوات برمجياً
- **LocalStorage**: حفظ البيانات محلياً
- **Responsive Design**: تصميم مستجيب

### البرمجة الكائنية التوجه (OOP)
اللعبة مبنية على نظام الفئات المنظم:
- `Player`: فئة اللاعب وحركته
- `Obstacle`: فئة العقبات المختلفة
- `Coin`: فئة العملات
- `PowerUp`: فئة العناصر المعززة
- `GameManager`: إدارة منطق اللعبة
- `SoundGenerator`: إنشاء الأصوات

## 🚀 التشغيل والتثبيت

### الطريقة الأولى: تشغيل مباشر
1. انسخ الملفات الأربعة في مجلد واحد
2. افتح ملف `index.html` في المتصفح
3. ابدأ اللعبة! 🎮

### الطريقة الثانية: على خادم محلي (Python)
```bash
# إذا كان لديك Python 3
python -m http.server 8000

# أو Python 2
python -m SimpleHTTPServer 8000

# ثم افتح: http://localhost:8000
```

### الطريقة الثالثة: على GitHub Pages
1. انسخ المستودع
2. ارفع الملفات على GitHub
3. فعّل GitHub Pages من Settings
4. الرابط: `yourusername.github.io/sabuyah`

### الطريقة الرابعة: على موقع استضافة مجاني
- استخدم **Netlify** أو **Vercel** أو **Firebase Hosting**
- اسحب وأفلت المجلد
- احصل على رابط عام مباشر

## 🔧 التطوير والتوسع

### إضافة عقبات جديدة
عدّل دالة `spawnObstacle()` في `game.js`:
```javascript
const types = ['train', 'car', 'barrier', 'yourNewObstacle'];
```

### إضافة عناصر معززة جديدة
أضف نوع جديد في فئة `PowerUp`:
```javascript
// في دالة draw()
else if (this.type === 'yourPowerUp') {
    // رسم العنصر الجديد
}
```

### تعديل الألوان
عدّل كائن `COLORS` في بداية `game.js`

### تغيير السرعة الأساسية
عدّل متغير `baseSpeed` (افتراضي: 5)

## 🐛 حل المشاكل الشائعة

**المشكلة: اللعبة بطيئة**
- تأكد من إغلاق البرامج الأخرى
- جرب متصفح مختلف
- تقليل جودة الرسومات ليس ضروري

**المشكلة: الأصوات لا تعمل**
- تحقق من أن الصوت مفعّل في الإعدادات
- تأكد من أن متصفحك يدعم Web Audio API
- ارفع مستوى الصوت على جهازك

**المشكلة: التحكم باللمس لا يعمل**
- اضغط بقوة أكبر
- تأكد من أن المتصفح يدعم Touch Events
- جرب متصفح آخر
